# Images Directory

Place your project images here:

## Required Images:

1. **profile.jpg** - Your profile photo (recommended: 400x400px or square, JPG/PNG)
2. **project1.jpg** - Screenshot of Project 1 (required, recommended: 1200x800px or similar, JPG/PNG)
3. **project2.jpg** - Screenshot of Hour of Code project (required, recommended: 1200x800px or similar, JPG/PNG)

## Image Guidelines:

- **Format**: JPG or PNG
- **Profile Image**: Square format works best (400x400px or larger)
- **Project Images**: Landscape format recommended (1200x800px or similar aspect ratio)
- **File Size**: Keep images under 1MB for faster loading
- **Naming**: Use exact filenames (project1.jpg, project2.jpg, profile.jpg)

## How to Add Images:

1. Save your image with the correct filename (e.g., `project1.jpg`)
2. Place it in this `assets/images/` folder
3. The website will automatically display it on the projects page
